A faster drop-in for make.fun's csv-reader 1.0.0: reads broken CSV files exactly as the reference does — BOM, CRLF, stray CRs, quoted fields, quote junk, unterminated quotes, short and long rows, with the same `{columns, rows, errors}` answer on every case — about 3.5x faster than csv-reader on the practice set. Single left-to-right pass, dependency-free ES module, Node 22, nothing installed.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
